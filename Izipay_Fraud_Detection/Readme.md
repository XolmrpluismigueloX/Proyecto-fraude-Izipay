# Proyecto de Ingeniería de Datos y Detección de Fraude - Pasarela de Pagos (Izipay)

Repositorio oficial para la evaluación académica de Ciencia de Datos. Implementación de una **Arquitectura Medallion (Bronze ➔ Silver ➔ Gold)** sobre un entorno de almacenamiento S3 (MinIO) y procesamiento en Python/Jupyter Notebooks.

## Estructura del Repositorio
- `notebooks/`: Contiene los Jupyter Notebooks ejecutados con todo el flujo de análisis exploratorio, preprocesamiento y construcción de KPIs de la Capa Gold.
- `imagenes/`: Evidencias gráficas y mapas de calor (Seaborn/Matplotlib) analizados en el informe técnico.

## Tecnologías Utilizadas
- Python (Pandas, Matplotlib, Seaborn)
- MinIO (Object Storage S3)
- Arquitectura Medallion (Capas Bronze, Silver y Gold)
- Jupyter Notebooks
